# C_Book
Code and notes related to the «[C programming](https://en.wikibooks.org/wiki/C_programming)» book on Wikibooks.


# Exercise prompts
In case you don't want to visit the Wikibook page, I'll list bellow the exercises
### String manipulation
1.) Write a program that prompts the user for a string (pick a maximum length), and prints its reverse.

2.) Write a program that prompts the user for a sentence (again, pick a maximum length), and prints each word on its own line.
### Loops
1.) Write a function that outputs a right isosceles triangle of height and width n.

2.) Write a function that outputs a sideways triangle of height 2n-1 and width n.

3.) Write a function that outputs a right-side-up triangle of height n and width 2n-1.
### Program flow
1.) Build a program where control passes from main to four different functions with 4 calls.

2.) Now make a while loop in main with the function calls inside it. Ask for input at the beginning of the loop. End the while loop if the user hits Q.
